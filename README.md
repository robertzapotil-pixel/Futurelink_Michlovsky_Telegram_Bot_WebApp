# Futurelink Telegram Bot — Mini App

Statický formulář (Telegram Mini App) pro bota [Futurelink_Michlovsky_Telegram_Bot](https://github.com/robertzapotil-pixel/Futurelink_Michlovsky_Telegram_Bot). Neobsahuje žádné tajné údaje — je to čistě HTML/JS formulář hostovaný přes GitHub Pages, jak to Telegram WebApp vyžaduje (veřejná HTTPS adresa).

Zdroj pravdy pro tento kód je hlavní (privátní) repozitář bota — soubor `webapp/zasuvky.html`. Změny se sem kopírují ručně.
